# 인천광역시서부교육지원청 스마트 청사안내

이 폴더는 GitHub Pages에 바로 올릴 수 있는 정적 웹사이트입니다.

## 파일
- `index.html` : 메인 화면
- `styles.css` : 모바일 화면 디자인
- `app.js` : 검색·필터·전화연결 기능
- `data.js` : 엑셀에서 변환한 공개 안내 데이터

## GitHub Pages 게시
1. GitHub에서 새 Public repository를 만듭니다.
2. 이 폴더의 4개 파일을 repository 최상단(root)에 업로드합니다.
3. Repository → Settings → Pages로 이동합니다.
4. Build and deployment에서 Source를 `Deploy from a branch`로 선택합니다.
5. Branch를 `main`, 폴더를 `/(root)`로 선택하고 Save합니다.
6. 잠시 후 Pages 주소가 표시됩니다.

## 주의
공개 전 아래 연락처는 원자료와 다시 확인하는 것을 권장합니다.
- 문서수발실: 부서전화 시트와 층별안내 시트의 번호가 서로 다름
- 교육시설과: 대표전화와 팩스가 동일하게 기재됨
